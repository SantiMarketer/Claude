# Claude

## 🚀 Un Viaje por el Sistema Solar (ebook infantil)

Un cuento educativo e interactivo de **20 páginas** para que los más pequeños
descubran el espacio de la mano de **Luna**, una astronauta, y su perro robot
**Cometa**.

El libro está hecho con HTML, CSS y JavaScript puro (sin librerías externas),
así que funciona **abriendo simplemente el archivo en cualquier navegador**, sin
necesidad de internet.

### ▶️ Cómo abrirlo

1. Descarga o clona este repositorio.
2. Abre el archivo [`ebook/index.html`](ebook/index.html) con tu navegador
   (Chrome, Firefox, Safari, Edge...).
3. Pulsa **«¡Empezar la aventura!»** y a explorar el espacio.

> Consejo: también puedes publicarlo gratis con **GitHub Pages** para leerlo
> desde el móvil o la tablet.

### ✨ Características

- **20 páginas** con texto sencillo pensado para niños de 5 a 9 años.
- **Ilustraciones SVG** dibujadas a mano (planetas, cohete, astronauta, galaxia...).
- Cajas **«¿Sabías que...?»** con datos curiosos y reales.
- **Quiz final interactivo** que corrige las respuestas y da una puntuación.
- **Navegación** con botones, flechas del teclado y gestos táctiles (deslizar).
- **Barra de progreso** y diseño **responsive** (se adapta a móvil, tablet y ordenador).
- Cielo de estrellas animado de fondo.

### 👩‍🚀 Para acompañantes (familias y profes)

El contenido es divulgativo y está simplificado para la infancia, pero los datos
son reales. Es ideal para leer en voz alta y comentar cada planeta. ¡Animad a
los peques a contar lo que han aprendido al terminar!
